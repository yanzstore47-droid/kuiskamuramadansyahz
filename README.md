# Kuis Buble — kuiskamuramadansyahz

Website kuis mobile-first dengan tema bubble, animasi gelembung, halaman nama, 10 pertanyaan, skor, gelar hasil, tombol bagikan, dan ulangi kuis.

## Struktur
- index.html
- style.css
- script.js

## Jalankan di Visual Studio Code
1. Buka folder `kuis-buble-kuiskamuramadansyahz`.
2. Buka `index.html`.
3. Jalankan memakai Live Server jika tersedia, atau buka langsung di browser.

## Ganti pertanyaan
Semua pertanyaan ada di bagian `const questions` pada `script.js`.
Setiap pertanyaan memiliki:
- `icon`
- `q`
- `a` = 4 pilihan
- `correct` = nomor jawaban benar, mulai dari 0
